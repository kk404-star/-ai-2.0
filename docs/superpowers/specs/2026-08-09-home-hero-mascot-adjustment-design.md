# 首页主卡标签与学伴形象调整设计

## 目标

精简今日学习主卡，并恢复用户更熟悉的旧版开窍学伴形象。

## 调整内容

- 删除主卡标题上方的“今日学习 · 当前学科”整行标签。
- 删除标签后由主标题自然向上补位，不保留空白占位。
- 将右侧方脸机器人 SVG 替换为改版前的学伴 SVG：绿色学士帽、黄色眼镜、蓝色眼睛、白色胶囊形头部和绿色衣领。
- 保留当前主卡的圆形装饰背景、尺寸、位置和减少动态效果支持。
- 不恢复旧版学伴下方的“开窍学伴”黑色徽标，避免挤占主卡内容。

## 不变范围

- 主标题、说明文案、今日完成比例和主按钮不变。
- 本周学习进程、知识点推荐、页面跳转和数据逻辑不变。
- 不新增图片资源或网络请求。

## 验收标准

- 主卡中不再出现“今日学习”或当前学科标签。
- 右侧展示旧版戴学士帽和眼镜的学伴 SVG。
- 390px 宽度下标题、学伴、说明文案和按钮互不遮挡。
- TypeScript 检查、生产构建和 GitHub Pages 部署通过。
