# 今日学习首页改版设计

## 目标

把当前以欢迎语、统计卡片和单一任务入口为主的首页，改成以“今天学什么、进度到哪里、从哪里继续”为主线的今日学习行动页。学生进入首页后，应能在几秒内明确下一步，并直接进入对应的学习或练习流程。

## 页面结构

### 1. 今日学习主入口

- 主标题固定为“今天，先从一个好问题开始。”
- 辅助文案说明系统已经结合学习进度和错题，整理好一组约 25 分钟的专注学习内容。
- 主按钮使用“开启今日学习”；点击后进入现有今日任务练习流程。
- 保留开窍学伴形象，但缩减装饰和动画强度，让标题与行动按钮成为视觉中心。
- 不再显示原首页的“你好，李同学”欢迎卡、三张统计卡和独立的今日任务卡。

### 2. 本周学习进程

- 标题使用“稳稳地推进”。
- 展示周一至周日的线性进度：已完成日期为品牌绿色，今天使用高亮圆环，未来日期使用浅灰绿色。
- 已完成日期下方显示学习分钟数；今天和未来日期不虚构分钟数。
- 下方显示连续学习天数，以及与上周相比的变化。
- 本周进度优先使用当前已有的学习天数和演示数据表达；未来接入真实按日统计时保持组件接口不变。

### 3. 今天从哪里继续

- 标题使用“今天从哪里继续”，上方辅助说明为“学伴为您推荐知识点”。
- 最多展示 3 个当前学科的推荐知识点，推荐顺序为：
  1. 学习中
  2. 已学习但尚未完成练习
  3. 未学习
- 每个知识点展示学科、所属模块、状态、知识点标题、简短学习提示和关联题目情况。
- 按状态显示不同操作：
  - 学习中：继续学习
  - 已学习：去练习
  - 未学习：开始学习
- “继续学习”和“开始学习”进入现有知识点学习页；“去练习”进入该知识点对应的练习页。
- 推荐区为空时，显示轻量空状态，并提供进入知识点列表的入口。

## 数据与交互

- 首页从现有知识树读取当前学科、知识点状态、题目数和已练题数，不建立第二套知识点数据。
- 今日任务的完成数和总数继续复用现有 `todayTaskProgress` 计算结果。
- 首页需要获得当前学科的推荐知识点列表，以及两个明确的回调：进入知识点学习、进入知识点练习。
- 所有卡片点击与卡片内按钮行为一致，避免出现无效热区。
- 点击主按钮、推荐知识点后继续沿用现有页面状态和返回逻辑。

## 视觉规范

- 延续项目已有的翡翠绿品牌色、白色卡片、浅灰背景和圆角系统，不引入新的视觉语言。
- 主入口使用浅薄荷绿背景与深色标题，品牌绿用于关键文字和主按钮；不复制桌面参考图的蓝色按钮。
- 页面维持当前约 390–420px 的手机端容器，并保留底部导航所需安全间距。
- 信息层级依次为主行动、本周进度、推荐知识点；减少首页大面积无信息留白。
- 动效只用于学伴轻微浮动和按钮反馈，并遵循减少动态效果的系统偏好。

## 边界状态

- 今日任务总数为 0 时，主入口文案改为引导浏览知识点，按钮进入学习页，不显示错误的完成百分比。
- 找不到“学习中”知识点时，自动使用下一优先级补足推荐项。
- 当前学科不足 3 个知识点时只展示实际数量，不使用占位内容。
- 长知识点名称最多显示两行，按钮保持固定宽度，不挤压主要信息。

## 验收标准

- 首页首屏能看到主标题、今日学习按钮和本周进度的主要部分。
- 页面清楚回答“今天学什么”“本周推进到哪里”“从哪个知识点开始”。
- 今日学习按钮能够进入任务练习。
- 推荐项能够根据状态分别进入知识点学习或练习。
- 切换当前学科后，推荐内容随之变化。
- 390px 手机宽度下无横向滚动、文字遮挡或底部导航覆盖。
- TypeScript 检查和生产构建通过，并完成首页手机尺寸的视觉检查。

## 本次范围外

- 不新增后端接口或账号级学习统计。
- 不修改学习页、练习页、错题页和个人中心的核心流程。
- 不实现桌面版首页或新的导航结构。
